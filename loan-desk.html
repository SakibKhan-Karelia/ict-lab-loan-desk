Save data to a private GitHub repository

  1. On GitHub, create a private repository for the data, for example ict-lab-loan-data. It can be empty.
  2. Create a fine-grained access token: choose “Only select repositories” and pick that data repository, then under Repository permissions set Contents to “Read and write”.
  3. Paste the token below and press Connect. The token stays in this browser only; repeat this on each computer you use.
Never share this token or put it in the public website repository.
